## ⚡ 创作者的两种姿态自由选择（Web 看板 vs 话题内纯血 Skill）

Hotdesk 支持两种完全不同的操作姿态，任何人可以根据自己的偏好与时间紧迫度自由选择：

| 操作姿态 | 适合场景 | 核心体验 |
| :--- | :--- | :--- |
| 🖥️ **姿态 A：Web 仪表盘 / MCP 模式** | 喜欢点界面、对照双语表格精修台词、在线试听分离音轨的创作者 | 打开 `http://127.0.0.1:4317` 或在外部 IDE (Cursor/Windsurf) 挂载 MCP 工具进行可视化操作。 |
| ⚡ **姿态 B：话题内纯血 Skill 模式（“双轨双话题 · 暴力炸金”）** | **心急、追求极致效率、想要端到端全自动产出的高阶创作者** | **彻底不碰 Web 客户端！**<br>• 开一个话题窗口专门做图文：甩一个热点词，后台子智能体跑完直接端出可复制的三平台成品稿；<br>• 开另一个话题窗口专门做短视频：甩一个 MP4 路径，后台全自动剥离伴奏/重构文案/混音，直接在话题内截帧预览、并直出剪映本地工程！两个话题同时狂飙！ |


Hotdesk 包含两条**在目标、输入、处理链路与产物形态上完全解耦**的生产线。在工作中切勿混淆：

| 维度 | 📝 纸质/图文文章创作 (Article Studio) | 🎬 短视频二创工坊 (Video Studio) |
| :--- | :--- | :--- |
| **核心业务定位** | 深度财经/社会/科技非虚构调查分析与热点长文 | 海外高赞科技/演讲/游戏视频汉化二创 |
| **主要分发渠道** | 今日头条（主力变现）、腾讯企鹅号、百度百家号 | 抖音、视频号、B站、快手、西瓜视频 |
| **输入源** | 全网热搜新闻、一手报道、当事人采访、统计数据 | 海外 1080P 原片 MP4（科技发布会、实机演示等） |
| **底层核心模型** | Gemini 3.1 Pro / 3.8 高推理集群（Tri-Agent 深度撰写） | Demucs v4 + Faster-Whisper + Edge-TTS |
| **声学工业标准** | 无音频需求 | EBU R128 (-14.8 LUFS) 母带压限；伴奏 35% + 解说 135% |
| **视觉与成片标准** | 正文附官方正版图库搜索词，零水印风险 | 1080P 高对比花字 MP4 嵌入 + 剪映 4 轨工程草稿直出 |
| **最终交付形态** | ZIP 交付包（各平台纯文本 + 插图说明 + 配图需求单） | 1080P 成片 MP4 + 剪映本地草稿（`JianyingPro Drafts`） |

## 2. 新环境冷启动与系统准备

当你在新电脑上接盘本项目时，请按照以下顺序完成环境自检：

### 2.1 基础依赖与命令检查
确保系统已安装以下基础设施：
1. **Node.js**：版本 `v22.0.0` 或更高（支持原生 ES 模块与内置测试框架）。
2. **Python**：版本 `3.12+`，并配备高效包管理器 `uv`。
3. **FFmpeg & FFprobe**：已添加到 Windows 环境变量 PATH 中（能在终端执行 `ffmpeg -version`）。
4. **网络代理通道**：由于依赖 Whisper/Demucs 预训练权重下载及 Edge-TTS 合成，确保本地代理（如 Clash 节点 `127.0.0.1:7897`）常驻。

### 2.2 启动 Web 本地创作看板
在项目根目录下执行：
```bash
npm start
```
服务将在后台监听：👉 **`http://127.0.0.1:4317`**
* 数据持久化目录：`data/hotdesk.sqlite`
* 媒体资源目录：`data/videos/` 与 `data/images/`

## 3. 【图文篇】今日头条爆款与多智能体深度生产 SOP

### 3.1 核心实战认知与平台分层定位
根据 2026 年实战复盘（单篇今日头条斩获 **35.6 万展现、近 3,000 阅读、首篇真金白银造血变现**），确立以下绝对铁律：

1. **今日头条绝对独尊**：
   - 平台单价最高、读者成熟、有深度长文耐力。
   - 所有最敏锐的视角、最扎实的数据算账、最硬核的商业逻辑，**100% 优先供今日头条独享**！
2. **企鹅号与百家号边缘化为“争论引流工具”**：
   - 下沉平台对宏观学术毫无兴趣，过度深度只会沦为无人问津。
   - 采用“真实事实打底 + 极端反差引战”打法，刺激评论区对立站队（测试显示数分钟内即可引爆争论推流），捡头条剩下的边角料每天各发一篇即可。

---

### 3.2 步骤 1：热点发现与读者切入点初筛
1. **热搜雷达扫描**：
   - 调用工具 `discover({ source: "baidu" | "bilibili" | "tieba" | "trendradar", limit: 12 })` 获取实时热点。
   - 也可以直接调用 `create_topic({ title: "选题名称" })` 人工立项。
2. **读者切入点（`reader_entry`）初筛**：
   - 严禁假大空的宏观叙事，必须回答四个核心问题：
     - **新变量是什么？**（最新发生的变化，不能拿三年前的旧事充当“刚刚发生”）
     - **目标读者是谁？**（明确是车主、二房东、打工人还是小餐饮老板）
     - **现实切身利益是什么？**（钱包会瘪、出行被堵、还是工作饭碗受冲击）
     - **未被回答的痛点是什么？**（大家都在困惑什么）

---

### 3.3 步骤 2：真实素材核验与事实提取（防造假护栏）
1. **多渠道素材采集**：
   - 调用 `collect_url({ topic_id, url })` 采集网页正文。
   - 硬指标清单：**搜索关键词 ≥ 6 个（必须包含 ≥ 1 个英文词），独立事实网站 ≥ 2 家**。
2. **防造假与事实锁死**：
   - 严禁 Agent 臆造采访名言、虚构网友评论或胡编点赞数。
   - 服务端会自动比对原文，未通过核验的素材标记为 `unverified`，禁止作为事实引用。
3. **抓取当事人可引用原话与本质（`essence`）**：
   - 专门收集采访对象、行业专家、一线员工的真实原话，记录为带编号的事实（如 `fact_1`, `fact_2`）。
   - **大白话讲本质**：提炼一段接地气的大白话“说白了到底是怎么回事”，不准堆砌社科伪概念。

---

### 3.4 步骤 3：权威与爆款对标拆解
调用 `claim_task` 处理 `benchmark` 阶段：
1. 选取 **2 篇权威媒体报道**（如晚点LatePost、人物、每日人物、界面等）+ **2 篇爆款自媒体文章**。
2. 拆解分析：
   - 它们用了什么叙事结构？开头用什么钩子吸引点击？
   - 大家都写了什么共识？（我们绝不再重复写！）
   - **它们遗漏了什么关键痛点？**（这正是我们切入的绝对差异化盲区！）
3. **查重护栏**：成稿与对标文章若存在连续 ≥20 个字相同，系统一票否决！

---

### 3.5 步骤 4：Tri-Agent Pro 三权分立深度撰写流
针对今日头条稿件，推荐派生/协同三位专职智能体：
* **智能体 A（主控 Antigravity）**：把控敏锐社会洞察、行文骨架与节奏。
* **智能体 B（深度学者 Scholar Pro - Model="pro"）**：开启深度高推理链，深挖底层商业/博弈运行机制与客观规律。
* **智能体 C（爆款大师 Viral Master - Model="pro"）**：专攻人性欲望、反常识避坑恐惧、极致痛点算账。
* **终极熔铸**：站在大众阅读心理学角度，融合三者长处，去粗取精，输出终极成稿。

---

### 3.6 步骤 5：今日头条 Rule 25 平民化烟火气实战法则
为彻底消灭“学者论文腔带来的距离感”，头条稿件必须严格执行 **Rule 25 创作准则**：

1. **标题规范**：
   - **严格限制 ≤ 30 个字符**（含标点符号）。
   - **严禁使用感叹号**，杜绝“震惊！竟然是它……”等营销号浮夸套路。
   - 格式建议：`【具象反差/矛盾博弈调查】：核心痛点现象`
   - *实战爆款范例*：《预判了别人的预判调查：第一批提前返程车主为何反被卡在路上》（29字，精准击中痛点）。
2. **前三句内必出戏剧冲突或现实反差**：
   - 严禁以宏观定义、抽象说教开头。第一段必须带入具体的人、地点或生活细节。
3. **文风是“老江湖在路边摊吃串唠嗑”**：
   - 彻底打破冰冷词汇，用市井烟火气和生活化比喻代替学术术语。
4. **算清柴米油盐的硬核经济账**：
   - 外壳幽默市井、笑中带思，但内核必须算清楚真金白银的利益账，给读者实操避坑建议。
5. **严禁造假与品牌堆叠**：
   - 严禁单篇商业平台名超过 1 次（改用“第三方平台数据”等指代）；限定免责句单篇不超过 2 处。

---

### 3.7 步骤 6：极速配图需求单（告别选图内耗）
根据复盘经验，彻底杜绝本地下载图片、Python 裁切水印耗费两小时的内耗：
* 系统自动在交付包中生成 **`配图需求单.txt`**。
* 为每一个配图位置提供：**段落位置、画面核心要素、平台正版图库精准搜索词、避雷注意项**。
* **发布实操**：创作者在今日头条/百家号后台发布时，直接点击编辑器内置的“正版免费图库”，输入搜索词，2 秒一键插入，零版权风险、绝对零水印！

---

### 3.8 步骤 7：成稿审查与三平台交付包导出

## 4. 【视频篇】海外短视频汉化二创 7 步工业流水线 SOP

### 4.1 路线 A 核心设计原则
* **彻底消灭老外说话声**：原视频是英语或其他外语，绝不搞低质量压原声混音，必须彻底抹除外语原声。
* **100% 完整保留现场环境音与伴奏**：按键声、掌声、环境音效、现场 BGM 必须纯净提纯。
* **音画严密贴合**：利用自研 `atempo` 算法微调语速，杜绝音画错位。
* **剪映 Pro 4 轨独立解耦直出**：原画、伴奏、配音、字幕互不干扰，随时在剪映电脑版二次精修。

---

### 4.2 步骤 1：高清原片获取与元数据探针 (`ingest`)
1. **素材获取规范（安全脱敏准则）**：
   - 涉及海外高清视频源下载时，**严禁在代码或 Git 中硬编码任何个人登录密令或专属凭据**。
   - 创作者在实战中会提供任意支持下载 1080P/4K 原画的解析网站（或下载工具）及账号密码。Agent 使用后将下载到的纯净 MP4 存入项目路径。
2. **项目创建与参数探针**：
   - 调用 MCP 工具：
     ```json
     create_video_project({
       "title": "项目名称",
       "file_path": "D:/素材目录/raw_video.mp4"
     })
     ```
   - 系统自动调用 `ffprobe` 提取视频时长、1080P 规格、帧率并初始化项目数据库。

---

### 4.3 步骤 2：Demucs v4 人声彻底剥离 (`separate`)
1. 调用 MCP 工具：
   ```json
   separate_video_audio({ "project_id": "vp_xxxx" })
   ```
2. **底层执行机制**：
   - 提取原片音频为 PCM WAV。
   - 调用 Facebook **Demucs v4 (htdemucs)** 双轨深度模型进行物理级人声与背景分离。
   - 产出两大核心音频切片（自动复制于项目顶层）：
     - `no_vocals.wav`：纯净的环境音效、游戏声与背景音乐。
     - `vocals.wav`：干净的老外人声（供转录识别）。

---

### 4.4 步骤 3：Faster-Whisper 毫秒级时间戳转录 (`transcribe`)
1. 调用 MCP 工具：
   ```json
   transcribe_video_audio({ "project_id": "vp_xxxx" })
   ```
2. **转录结果**：
   - 毫秒级提取每句话的开始时间（`start`）、结束时间（`end`）和英文原句（`en_text`）。
   - 生成精准的声波时序切片数组。

---

### 4.5 步骤 4：2026 短视频网感剧本重构 (`script`)
1. **中文网感重构准则**：
   - 彻底删除英文里的口癖与废话（如 "Like you know", "Basically", "To be honest"）。
   - 句式短促有力，多用主动动词，强化开门见山的反差感。
2. **双语在线对照与编辑**：
   - Web 看板提供双语对照编辑表格，创作者可随时调整中文配音台词。
   - 调用 MCP 工具更新剧本：
     ```json
     rewrite_video_script({
       "project_id": "vp_xxxx",
       "segments": [
         { "start": 0.0, "end": 3.2, "en_text": "...", "zh_text": "兄弟们看这个全新人形机器人！" }
       ]
     })
     ```

---

### 4.6 步骤 5：Edge-TTS 自适应微加速语音合成 (`synthesize`)
1. 调用 MCP 工具：
   ```json
   synthesize_video_voiceover({
     "project_id": "vp_xxxx",
     "voice": "zh-CN-YunxiNeural"
   })
   ```
2. **自适应 `atempo` 算法**：
   - 中文朗读字数与原片英文时间槽天然存在长短差异。
   - 系统计算物理时间槽长度与 TTS 音频长度的比值，在 `0.9x ~ 1.35x` 范围内执行微加速处理，确保每句话刚好在画面结束时说完，严丝合缝咬合画面口型！

---

### 4.7 步骤 6：EBU R128 (-14.8 LUFS) 工业级母带混音 (`mix`)
1. 调用 MCP 工具：
   ```json
   mix_video_audio({ "project_id": "vp_xxxx" })
   ```
2. **母带混音工业参数**：
   - **提纯伴奏音量衰减至 35% (-9.1 dB)**：作为环境氛围垫底，绝不喧宾夺主。
   - **中文解说配音提升至 135% (+2.6 dB)**：清晰通透、洪亮入耳。
   - **EBU R128 标准压限**：整片音频应用 Dynaudnorm 动态压限，母带总响度稳定在 **-14.8 LUFS**（手机端听感最佳标准）。

   - **剪映 Pro 本地 4 轨工程**：基于 `pyJianYingDraft` 自动构建位于剪映草稿目录的项目文件夹：
     - **Track 1 (视频原画)**：原始 1080P 画面无损。
     - **Track 2 (纯净伴奏)**：Demucs 提纯的现场音效与原声 BGM。
     - **Track 3 (中文配音)**：自适应微加速对齐的中文解说音频。
     - **Track 4 (解耦花字字幕)**：毫秒级时间戳文本字幕轨，在剪映中字体、动效、花字一键随意替换。

## 6. 故障排查与应急手册 (FAQ)

### Q1: 页面显示“连接中断”或无法打开 `http://127.0.0.1:4317`？
* **排查方法**：终端运行 `npm run check`，无语法错误后运行 `npm start` 重新挂载服务。
* **数据安全**：所有数据均持久化在 SQLite 中，重启服务不会丢失任何已有话题或视频进度。

### Q2: Demucs 分离或 Whisper 转录报错显存不足 (OOM)？
* **解决方案**：Worker 脚本默认已开启 CPU 模式（`-d cpu` 及 `device="cpu", compute_type="int8"`），在普通 CPU 上稳定运行，彻底杜绝 GPU 显存崩溃。

### Q3: Edge-TTS 语音合成连接超时？
* **排查方法**：Edge-TTS 依赖出海连接，脚本已默认挂载 Clash 本地代理 `http://127.0.0.1:7897`。请确认本地代理服务正常开启。

### Q4: 剪映打开后找不到自动生成的草稿？
* **排查方法**：剪映草稿目录默认检测路径为 `C:\Users\<当前用户名>\AppData\Local\JianyingPro\User Data\Projects\com.lveditor.draft`。若安装在不同盘符，可以在创建草稿后直接复制日志中打印的绝对路径手动导入。
