# Hotdesk v0.4.0 (Gemini版 · 多智能体深度流水线)

### 🌟 版本亮点与定位
本版本为 **Gemini 多智能体深度流水线体系（对照组生产体系）**。
与传统的粗放式生成或单智能体模式不同，本版本通过**主控中枢编排 + 专项子智能体集群**，实现了工业化、高质量的自媒体内容生产与双重质检把关。

---

### 🚀 核心架构与功能

1. **多智能体蜂巢协同**：
   - **主控调度中枢 (Master Agent)**：负责任务生命周期编排与调度；
   - **素材侦查员 (Material Scout)**：负责全网定向深挖真实案例（有名有姓有制度）、部委大盘统计；
   - **深度撰写流 (Master Writer)**：以财经调查与社会学非虚构视角切入，三平台差异化定制写作；
   - **事实审查员 (Fact Auditor)**：地毯式排查 AI 幻觉，专门纠偏网络失实传言（如威马 10 万 vs 哪吒 40 万销量剥离、时序对齐）；
   - **视觉质检室 (Visual Auditor)**：3×3 矩阵实拍检索，核验三大红线，并用 Pillow 算法像素级裁切清除水印。

2. **三大平台差异化原型**：
   - **今日头条**：标题严格 ≤ 30 字符，严肃非虚构调查风，杜绝浮夸感叹号与营销号套路；
   - **腾讯企鹅号**：深度纪实特写与时代阵痛，长篇沉浸式人物命运剖析；
   - **百度百家号**：宏观产业经济与底层商业机制剖析，**100% 杜绝 Markdown 表格**。

3. **视觉资产与 Pillow 像素级无损去水印**：
   - 3×3 矩阵轻量化隔离，真实新闻摄影；
   - 自动切除新华社、央视等边框角标，实现 100% 绝对零水印。

4. **Rule 18 并发抢跑与 Rule 19 下班后逐篇交付**：
   - 工作时间后台静默批量跑批，做完后安全沉淀本地磁盘，绝不打扰用户；
   - 下班后用户唤醒，一次只发一个热点，发布完毕秒级端出下一个，彻底消灭等待时间！
