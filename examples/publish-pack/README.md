# v0.2.1 完整流程实测成果样例 (Live Run Deliverable Pack)

本目录为 Hotdesk v0.2.1 规则下通过全流程工序实测生成的真实交付包（Topic ID: `t_96c9d5c0-cde`）。

## 选题基本信息
- **选题名称**：“原生旅游”火了
- **发现时间**：2026-10-01（国庆首日出行热点）
- **评级判定**：A 级（热点初筛，情绪反差与反向旅游深化）
- **核心本质**：反伪奇观消费与本真性补偿（受够了人造景区排队买轰炸大鱿鱼，追求真正有烟火气与松弛感的乡土山野）

## 全工序实测记录
1. **素材采集 (`collect`)**：采集中华网、新浪财经、百家号等 5 篇门户及权威新闻报道，提取完整正文与正文原图。
2. **热点初筛 (`editor`)**：综合争议度、饱和度与传播深度，确定评级 A 并走深度研究链路。
3. **事实研究 (`research`)**：提取 F1~F5 事实断言（跨域逐字比对核验），形成 7 条中英文检索词，给出通俗化本质阐述 E1。
4. **舆情态度 (`opinion`)**：由于采集信源均为门户快讯无可见评论，严格按规则触发 `insufficient` 真实性保真兜底，未凭空捏造评论。
5. **对标拆解 (`benchmark`)**：采集权威媒体与爆款自媒体各 1 篇，定位同质化共识与未覆盖差异缺口（G1、G2）。
6. **角度标题 (`angles`)**：选定 A1 切角，生成 6 组适配头条 30 字严格限长的爆款标题候选。
7. **正文生产 (`write`)**：
   - 今日头条：结果反差与情绪共鸣（1420 字符）
   - 企鹅号：事件演进与真假文旅对比（1715 字符）
   - 百家号：消费动机与平台数据深入解答（1686 字符）
   - **查重验证**：成稿与对标文章连续重复字数严格控制在 20 字以下（查重率 0%）。
8. **视觉资产 (`images`)**：提取自中华网报道正文实拍摄影图（SHA-256 校验），按平台分配封面图与插图说明。
9. **成稿检查 (`review`)**：全量检查项均达标（verdict: pass），状态推进至 `done`。
10. **交付打包 (`export_publish_pack`)**：导出规范化平台交付包与 ZIP 压缩包。
